# Distributed Search Engine

A scalable distributed search engine implemented primarily in C++20.

## Project Status

Phase 0 — Project Foundation

## Objective

Build a search engine from first principles and progressively introduce:

- inverted indexing
- information retrieval
- BM25 ranking
- persistent index segments
- concurrent search
- distributed sharding
- consistent hashing
- replication
- fault tolerance
- distributed caching
- asynchronous indexing
- observability
- performance benchmarking

## Core Technologies

- C++20
- CMake
- GoogleTest
- Docker
- Redis
- Apache Kafka
- PostgreSQL
- Nginx
- Prometheus
- Grafana

All infrastructure is intended to run locally without paid cloud services.

Architecture documentation will be added progressively as the system evolves.

## Development

The project is developed incrementally. Each phase introduces new concepts and functionality while keeping the system testable and measurable.
